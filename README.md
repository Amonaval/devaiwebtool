# Runtime Proof

**Understand what should have died, discover why it did not, and prove the correction.**

Runtime Proof is a small framework-agnostic experiment for progressive runtime degradation and resource-lifetime defects. The browser kernel records resources; semantic adapters explain ownership for Lit, React and Angular; controlled replay measures whether an intervention actually removes the growth.

## Why this is different
It does not start with another dashboard or another LLM wrapper. It creates compact runtime evidence and refuses to call correlation causality without the required proof.

## Run

```bash
npm test
npm run demo
npm run verify
```

No runtime dependencies are required for the proof repository.
